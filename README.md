# Html

Concluí o curso de Git e GitHub disponibilizado pelo Curso em Vídeo, do professor Gustavo Guanabara.

Neste projeto, vou colocar em prática os conhecimentos adquiridos durante o curso, utilizando HTML para criar um site e Git/GitHub para controlar e versionar o projeto.

Durante o desenvolvimento, também vou praticar a criação de branches, commits, push e outras funcionalidades do Git e GitHub.
